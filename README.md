# Z&S Enterprises

> Responsive business website for a Karachi-based packaging and printing company.

[![Live Website](https://img.shields.io/badge/Live_Website-Visit-21C7E8?style=for-the-badge&logo=googlechrome&logoColor=white)](https://zandsenterprises.com/)

## Overview

This independently developed website gives **Z&S Enterprises** a digital presence for presenting the company, its packaging and printing work, and business information. The frontend focuses on professional presentation, straightforward navigation and responsive layouts.

## What It Focuses On

- Professional company presentation
- Product and industry-focused content
- Responsive layouts for different screen sizes
- Clear company and contact information
- Clean frontend structure without unnecessary complexity

## Site Overview

The website presents company information, packaging products and services, industries served, and contact details through a responsive frontend. The repository contains HTML pages, JavaScript interactions and CSS assets under `assets/css/`.

## Local Preview

Clone or download this repository and preview its HTML pages with a local web server (for example, VS Code Live Server). A local server is recommended because some assets use root-relative `/assets/` paths. No PHP/MySQL setup is required for the documented frontend.

**Known domain-metadata discrepancy:** The current `index.html` contains canonical, Open Graph and structured-data URLs referencing `https://www.zspackages.com/`. The confirmed primary website is `https://zandsenterprises.com/`. This README records the inconsistency only; no HTML metadata, redirects or hosting settings were changed.
